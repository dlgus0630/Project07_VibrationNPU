# C 골든 모델 함수 분리 검증

입력 정렬, FFT, 대역 특징, 은닉층, 출력층을 이름 있는 함수로 분리하고
중첩 계산과 삼항 조건을 중간값·`if`문으로 풀어 쓴 코드의 검증 기록이다.
공개 함수·결과 구조체·가중치·twiddle과 정수 연산 규칙은 유지한다.

| 파일 | 내용 |
|---|---|
| `golden_before.c` | 변경 전 원본 C. SHA-256은 검사 도구에 고정 |
| `golden_equivalence.json` | 원본/현재 C의 입력·소스 지문과 전체 결과 필드 비교 |
| `offline_report.json` | 기존 20개 기준 입력과 Python/C 검사 |
| `preservation.json` | 나머지 원본 파일과 기존 측정·증거 해시 보존 검사 |
| `arm_compile.json` | Cortex-A9용 C 컴파일 명령·도구·결과와 소스 지문 |

각 윈도우에서 FFT 실수 64개, 허수 64개, 특징 4개, 은닉값 4개,
logits 2개, 클래스 1개로 총 **139개 값**을 비교했다.

| 입력 구분 | 윈도우 수 |
|---|---:|
| 기존 기준 입력 | 20 |
| 원본 실측 진동 입력 | 360 |
| 경계값·impulse·교대값·ramp 시험 입력 | 271 |
| 고정 seed 난수 시험 입력 | 10,000 |
| 합계 | **10,651** |

경계값과 난수는 소프트웨어의 수치 비교용 입력이다.
원본 C와 현재 C는 UBSan을 켜고 컴파일해 모든 비교를 통과했다.
기존 실측 CSV·사진·ELF·타이밍 보고서는 보존한다.
이 폴더의 변경 사항은 C 골든 모델이며, VHDL 회로는 이전 검증 소스를 유지한다.
